# Drag-and-drop fixtures

These files are development fixtures for manually testing the Animal Buddy drop target:

- `AnimalBuddyTestImage.svg`, `AnimalBuddyTestImage.png`, and `AnimalBuddyTestImage.jpg` should show the camera and SD-card presentation.
- `AnimalBuddyTestText.txt` is a generic file and should show the document presentation.
- `AnimalBuddyTestURL.webloc` should show the envelope and link presentation.
- `AnimalBuddyTestFolder` exercises directory detection and should show the storage-box presentation.
- `AnimalBuddyTestApplication.app` exercises application detection and should show the document presentation.
- Select the image and text fixtures together to exercise the explicit mixed-drop presentation.
- Copy plain text from another app and drop it to exercise the text-only context.
